# SPEC

## 当前状态

以下为当前代码已经实现的契约，类型见 shared/protocol.ts，入口见 server/app.ts。首版一个共享空间，协议 v1，二进制使用标准 Base64；时间戳为 Unix 毫秒。

## 身份与 HTTP

邀请和恢复码只在兑换时提交，数据库只存摘要。HTTPS 会话为 __Host-pt_session，HttpOnly、Secure、SameSite=Strict、Path=/；回环 HTTP 测试使用 pt_session。写请求和 WebSocket 必须匹配配置 Origin，不接受跨源写入或 CORS。

JSON 请求上限 16 KiB，失败返回 HTTP 状态和 {code}，不返回内部异常。资源 ID 仅接受字母、数字、下划线和连字符。成员为 {id,nickname,role,owner,active,accessRevision}，role 为 manage/edit/view。accessRevision 从 0 开始，角色或活跃资格实际变化时递增；恢复会话不重置该值，无变化的角色保存不递增。该字段补充协议 v1 的成员信息，不能作为客户端认证凭据。

应用静态模块（含 PDF worker 的 .mjs）使用 text/javascript，WASM 使用 application/wasm，并保留 X-Content-Type-Options: nosniff。静态程序和字体资源可缓存；附件内容仍经已鉴权 API 或本成员缓存读取，没有新增公开附件 URL。

同源根路径的 `?doc=:id` 和原生 `/workspace/main/:id` 均可导航到目录中当前获准访问的文档。后者仅返回公开应用壳，不返回正文；其他 workspace 路径不作通配回退。不存在或已删除的目标明确提示，不能借链接恢复文档或跳过 API 鉴权。

定位查询接受 `mode=page|edgeless`、逗号分隔的 `blockIds` 或 `elementIds`、`databaseId`、`databaseRowId` 和 JSON 数组 `xywh=[x,y,w,h]`。标识去重后每组最多 100 个，每个最多 512 字符；坐标须为有限数、绝对值不超过 1e9，宽高为正。无效参数丢弃，仍允许打开获准文档。当前聚焦首个标识，画板无标识时可按坐标聚焦；数据库行必须属于指定数据库，通过原生详情面板打开，当前筛选不阻止查看该行；定位目标缺失则打开文档并提示。链接跳转、初次加载和历史导航使用同一解析，不能改变授权或生命周期。

| 接口 | 行为与权限 |
|---|---|
| POST /api/auth/invite | {token,nickname}，一次兑换，签发会话 |
| POST /api/auth/recover | {code}，恢复所有者并返回新 recoveryCode，旧码和旧所有者会话失效 |
| GET /api/session | {member,epoch,paused}，恢复维护时仅所有者可访问 |
| POST /api/logout | 失效当前会话并清 Cookie |
| GET /api/members | 当前成员列表，任何有效成员可读 |
| POST /api/invitations | 管理者提交 {role,memberId?,recovery?}，返回 {id,token,expires}；仅所有者可为原成员恢复身份或增加设备 |
| DELETE /api/invitations/:id | 管理者撤销邀请 |
| PATCH /api/members/:id | 管理者提交 {role,active}；任免管理者仅所有者可执行，不能降级或移除所有者 |
| GET /api/documents | 有效成员读取目录；?trash=1 仅管理者可读 |
| GET /api/documents/:id/state?epoch=:epoch&generation=:generation | 有效成员按当前空间及文档代际读取完整 Yjs update，返回 {docId,epoch,generation,update,revision,member}；no-store，不创建 WebSocket |
| POST /api/documents | 编辑以上提交 {id,title}，同 ID 重试返回已有文档，不能复活回收站文档 |
| POST /api/documents/:id/initialize | 编辑以上提交 {epoch,generation,accessRevision}，仅对无 Yjs 历史的空记录原子初始化；返回作用域、update、revision、member 和 initialized，已初始化重试不新增修订 |
| POST /api/documents/:id/trash 或 restore | 管理者推进生命周期及文档代际，不永久删除 |
| GET /api/blobs | 有效成员读取已提交附件键列表 |
| PUT /api/blobs/:key | 编辑以上上传原始字节，必须携带下述上传作用域；校验内容地址、限额与当前权限，索引提交后返回 {key,size,saved:true} |
| GET /api/blobs/:key | 有效成员下载已索引附件，可携带预期空间代际；撤权终止现存下载 |
| POST /api/maintenance/resume | 仅所有者解除备份恢复后的暂停状态 |

文档目录为 {id,title,generation,revision,deleted,createdAt}。标题通过原生 page 块的 Y.Text 修改，与正文一起保存，SQL 目录为其投影。目录创建与原生初始化仍为两个步骤，但挂载前会读取当前授权和内容，联网且具备当前编辑权限时自动修复真正空文档。初始化事务复核权限版本、空间代际及未删除的当前文档代际；已有内容或删除历史却无根节点返回 409 document_initialization_conflict，保留现场供人工恢复。

初始化生成固定版本的 page、surface、note、paragraph 四块及原生 Yjs 包装结构，使用既有保存事务。多个初始化请求只提交一份内容。任何推送合并后出现多个 page 根节点返回 409 document_root_conflict；浏览器在应用远端更新前同样检查本机初始化竞态，暂停并保留尚未合并的完整原稿，不能污染云端或丢弃本机根节点。

附件键遵循 BlockSuite 的 SHA-256 Base64URL 格式，保留末尾等号；请求路径需编码。附件不存在返回 404，哈希错误返回 400，单附件或总配额超限返回 413，并发上传忙返回 429。没有公开下载地址或永久删除接口。

PUT 必须携带 `X-PageTogether-Upload`，值为 JSON `{docId,epoch,generation,memberId,accessRevision}`，最长 2048 字符。接收前、异步文件工作后及索引事务内均核验身份、权限版本、空间代际和当前未删除的文档代际；成员或权限版本不符返回 409 `access_changed`，代际及删除错误沿用文档错误。缺失头返回 400 `upload_context_required`，格式非法返回 400。该契约收紧了原上传接口，旧页面须刷新至配套构建后上传；WebSocket 协议仍为 v1。

GET 可携带 `X-PageTogether-Epoch`，与当前空间代际不符返回 409 `space_epoch_changed`。原生客户端使用此头并在写缓存前核对大小和 SHA-256；缓存及下载链接不作为认证凭据。已存在的同内容附件可重复提交，但每次仍须通过当前上传作用域核验。

## WebSocket 同步与保存确认

/api/sync 复用会话和 Origin。ready 返回当前 member 和空间 epoch。每个 open/push/awareness 均包含 {v:1,requestId,docId,epoch,generation}，并在操作时核验当前成员及生命周期。

- open 带 stateVector，sync 返回缺少的 update、服务端 stateVector 和 revision。
- push 带 update，必须已 open；服务端在 SQLite 同步事务内校验、保存并推进 revision。
- 提交成功后 saved 返回原 requestId、updateHash（SHA-256 十六进制）、revision 和完整文档作用域，再向获准订阅者广播 update。
- 客户端核对作用域和摘要，只删除该请求包含的待发记录。重复 Yjs 更新可安全重试，不重复推进修订号。
- catalog 提示重新读取目录；错误为 {v:1,type:error,requestId?,code}。数据库提交失败不发 saved 或广播，不污染后续拉取结果。

权限版本或会话失效关闭连接，文档删除或代际改变关闭旧订阅。典型错误为 session_expired、read_only、space_epoch_changed、document_deleted、document_generation_changed、storage_unavailable、document_root_conflict；客户端保留离线稿，网络或存储服务故障重试，身份、生命周期或初始化冲突暂停上传。暂停跨刷新及身份恢复生效；有待发修改且授权版本变化或缺失时不自动上传，即使当前角色已恢复编辑。

awareness 的 update 为标准 Awareness 二进制的 Base64，客户端单次仅提交自身一条状态，解码上限 16 KiB；须先 open 相同文档作用域。服务端将客户端 ID 绑定到该连接，拒绝覆盖其他连接的 ID，昵称、成员 ID、角色和颜色由服务端生成。仅保留本版本的原生 text/block/image/cursor/surface 选择结构，限制条目和字段大小。查看成员可发送获准的远端状态，不能借此写正文。

open 后返回该房间已有状态；临时状态变化和离开均向当前获准订阅者广播同作用域 awareness。撤权、会话失效或文档代际变化清除该连接状态。Awareness 不产生 saved、修订号或数据库写入，不代表正文已保存。当前文档在线人数按成员去重，多个页面另行提示；切换文档退出原文档活跃状态，离线不显示过时人数。

本机正文写入或待发确认清理失败时持续显示保存失败，保留内存并暂停上传；明确重试先保存完整内存快照，再恢复获准的同步。异常暂停与存储失败分别保存状态，重试存储不能解除异常授权暂停。离线稿只读对照不修改源数据；人工追加使用当前已核验的编辑身份和文档代际，先保存目标快照，再添加用户确认的文字，不能直接应用整个旧 Yjs 更新或覆盖当前文档。

当前每个已打开文档持有独立连接。本机验证已覆盖 10 人各 4 条连接共 40 条，主文档含 1000 个段落，其余 3 篇为空文档；超过该打开文档数或多个设备的容量仍待测，完整固定方案见 [CAPACITY](CAPACITY.md)。

引用本机待发附件的正文等待该附件的服务端保存确认及本机回执写入。网络失败保留队列并重试，配额异常可明确重试；身份、权限或生命周期异常持久暂停。明确重新提交附件前，在同一本机事务中保存原始副本及新的待发记录，再按当前作用域上传并追加卡片。旧空间附件、原始副本及异常正文继续保留，旧上传回执只能确认其对应的本机队列记录。

## 原生脚注

正文发送前的附件引用盘点覆盖普通附件与图片块，以及全部富文本属性中的 `footnote.reference` 附件 `blobId`，包括嵌套表格单元格；不能因删除附件卡片而跳过脚注原件的保存确认。原生脚注文档跳转复用当前获准工作区，原件下载复用鉴权 BlobEngine。URL 脚注只允许 HTTP/HTTPS，缺失、不可读取或可执行协议明确提示并保留原属性；异步下载若已切换文档则停止。

## 独立待办汇总

affine:data-view 的独立待办汇总使用原生 views、columns、cells 模型，扫描当前获准工作区中的 todo 列表块。行标识为 `文档 ID/块 ID`，避免原生导入后相同块编号串行。固定完成列写回原始 todo，固定来源列导航到原文，标题从原文只读展示；额外属性和视图保存在汇总块中。表格的 `views[].manualRowOrder` 保存当前视图的组合行键顺序，不移动来源块；字段排序优先，看板与分组表格继续使用原生 `groupProperties[].manuallyCardSort`。未分组表格保留缺失来源的已有顺序，新行追加；无效顺序数据按默认来源顺序读取。

挂载时核验目录并读取未缓存或修订变化的来源，约每 3 秒复核；读取来源不另建文档连接。明确编辑来源才进入原有鉴权同步和保存确认，编辑前复核身份、权限、空间与文档代际及本机保存状态。失去资格、被删除或恢复的旧来源不能通过汇总绕过保护。离线只读入已有且仍可用的本机缓存，未缓存及无法读取的来源明确提示不完整。独立离线稿预览仅展示本篇快照中的待办，不联网加载其他文档。

浏览器联网提示不能证明服务可达。目录网络或服务错误时，读取经过本机授权记录检查的缓存并提示核验失败；401、403、409 不走此回退。排序和自定义属性仍保存到当前汇总的既有本机队列，重连继续遵守身份、权限、代际及服务端保存确认。

来源创建时间读取原始待办的元数据，不从汇总的子块查找，也不接受单元格覆盖。旧格式的直接值和原生包装单元格复制后均保留值，富文本副本独立。属性转换同时处理当前来源和已保留的单元格，列定义与结果在同一事务写入；来源暂时删除或尚未加载不应留下旧类型值。查看成员、固定列、同类型和未知目标类型不发起转换。

属性互转沿用固定上游十四条已定义路径。多选转单选只取首项，数值转进度限定为 0 至 100 且空数值变为零，文本转进度按整数解析，文本转数字使用原生浮点解析；无转换器的类型组合按原生规则清空值。转换可能损失内容或格式，可先复制属性，转换后可撤销。特殊名称作为普通标签处理。

隐藏列继续参与表格及看板筛选，沿用原生空值、数值、勾选、标签和日期语义；空值不同于零或 false，未填完整的筛选条件暂不限制行。更多组合的逐行验收见 EDITOR_CAPABILITIES。

图片类型沿用原生字符串值及隐藏预设，不新增上传接口；已有值可展示和作为桌面看板封面，空值不创建图片元素。失败显示明确提示，可在当前 URL 上手动重试，查看成员同样可重读；加载状态不写入文档、不增加修订。图片请求不发送 Referrer，不强制要求图片源提供 CORS 才能展示。外链保留原 URL，不经服务端代理，不自动进入附件或离线缓存；源失效或不可达时仍保留原值。内嵌图片随原生内容保存；外链资源的离线可用性及 PNG/PDF 视觉保真不作承诺。

## 内容导入导出

原生 ZIP 对脚注使用同一引用盘点：包内 `footnote.reference.docId` 改为新副本 ID，包外引用、标签及描述不改；仅由脚注引用的附件也必须打包、校验并在应用正文前写入附件保存层。缺少原件或摘要不符时，在创建任何文档前拒绝；迁移清单仍为 format 1、BlockSuite 0.22.4，不改变其字段。

原生内容包为 ZIP，包含 `*.snapshot.json`、`assets/` 和 `pageTogether.json`。清单为 `{format:1,blockSuite:"0.22.4",assets:[{key,path,type,name?}]}`，快照使用该版本公开 DocSnapshot。支持单独导入兼容的原生 JSON；存在附件引用时必须提供完整资源包。块类型、版本、根节点、父子关系、块 ID 唯一性和附件完整性在创建任何文档前校验，单篇最多 20000 块。

导入始终创建新文档，预分配 ID 后重映射包内行内、卡片、同步嵌入及画板引用的文档 ID；块、图形、画框和数据表标识保留，包外引用不改写。已有文档不覆盖。导入须联网并重新核验当前编辑身份，实际写入和附件继续经已有鉴权与保存确认；中途权限变化或失败暂停后续处理，保留已创建内容，不自动回滚删除。

独立汇总的包内来源行标识、表格手动顺序及原生分组顺序随新文档 ID 重映射，自定义属性保留；包外来源仍指向原文。原生导入保留快照中的块创建及修改元数据，不用导入时刻或当前成员覆盖。新建记录继续由当前编辑身份产生原生元数据，创建时间字段只读；缺失历史元数据的旧记录初始为空，后续编辑可能由原生服务记录当次时间，不能据此认定其历史创建时间。

Markdown、HTML、TXT 使用原生适配器；复杂原生内容可能投影为静态表格、文字或丢失交互。含图片的 Markdown/HTML 导出 ZIP，资源路径与文内 URL 一致。Notion HTML 通过明确选项启用原生专用解析，并按源文件相对路径处理包内链接；没有宣称支持所有 Notion 导出。PNG/PDF 使用原生视觉导出，不包含可编辑原生数据。

视觉导出保留当前可读视图，查看成员也可生成文件。生成完成后显示带文件名的明确下载入口；未产生文件、资源失败、超时或文档视图已变化时不得显示成功。外链从浏览器直接按 CORS 读取，不向上游公共代理发送 URL；同源请求沿用同源凭据，跨源省略凭据，不发送 Referrer。无 CORS 图片可普通显示，但视觉导出明确停止，源 URL 和文档保留。

单图片读取按实际响应字节限定为 50,000,000，最多三项预读并发；请求、解码各设 10 秒截止，所用画板字体设 20 秒等待，原生就绪检查最多约 10 秒。已知样式扩展会阻止视觉导出并提示换用未启用该扩展的窗口。克隆副本中的 SVG 尺寸、数据视图图片比例及现代 CSS 颜色转换不写回模型；单个数据视图图片的克隆画布在分配前限定 16,000,000 像素。限额不代表已完成全部大图或整篇视觉导出容量验收。

PDF 是原生栅格视觉页面，PNG 可以带透明背景；两者不保证可检索文字或可编辑结构。原生七种字体保持原选择，追加同源 pageTogether Han Supplement 的字形回退，正文、画板测量和绘制使用一致字体栈。固定 BabelStone Han 16.0.3 的补充平面子集含 32,993 个映射，WOFF2 为 4,824,780 字节，随应用预缓存；公开清单保留范围和摘要，许可与修改名一并保留。导出明确等待补充字体的 loaded Promise，不能用字体集合 ready 在加载失败后仍会完成的状态替代。五个罕见汉字已在 Chrome 实际文件核对，其他字符及系统脚本字体不能据此全部验收。Safari 的新增字形导出仍待验，先前外链与脚本证据保持原范围。

画板导出使用原生视口接口临时激活视口外区块，等待完成显示后读取资源并栅格化。无论成功或失败，按当时视口和选择恢复显示状态，不改模型或坐标。仍为零尺寸的区块明确停止导出，不交付空白结果。更多浏览器、扩展、移动端与任意外链仍需独立验收，具体见 EDITOR_CAPABILITIES。

静态数据表投影将标题表头与原生适配器的首列标题值对齐，创建时间按 `+08:00` 文本导出；这些转换仅作用于导出副本。金额、百分比导出原始数值，筛选、显示格式及交互不随静态表格保留。实际复杂格式损失及原生往返对照见 EDITOR_CAPABILITIES，不将文本包当作完整备份。

每批最多 100 篇支持格式文档、2000 个压缩条目；输入 ZIP 和实际解压总量各最多 100,000,000 字节，单个条目及附件最多 50,000,000 字节，单篇文本或原生 JSON 最多 10,000,000 字节。拒绝不安全或重复路径、不完整压缩包、未支持的压缩方法及嵌套 ZIP；UTF-8 严格解码。原生附件按内容键验证 SHA-256，缺失或不符时不创建文档。导出也检查内容大小，不能把限额当作完成相应容量验收。

这些是浏览器内容迁移边界，服务端 8 MiB 正文、空间文档数、附件配额和 40 条连接保护独立生效。本轮完整往返为 25 篇文档及 6 个附件，空间导出加载的文档也会占用连接；更大批次或多人同时迁移仍待测。服务身份、权限与完整恢复使用 server:admin 备份，不包含在此内容包内。

## 保存、备份和资源边界

本站存储估算使用 `navigator.storage.estimate()`，仅接受有限非负 usage 和有限正 quota，达到 90% 时提示保留页面、导出和恢复空间后明确重试。查询合并、最多等待 5 秒；首次、可见页面每 30 秒、重新可见及手动刷新触发。不可用不报告为有剩余空间，后续失败保留上次读数并说明；退出工作区停止观察。浏览器可能返回经安全混淆处理的近似值，依据 [StorageManager.estimate 文档](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/estimate)；百分比不替代实际保存确认，也不触发原始数据清理。

Service Worker 安装缓存失败时，只删除本次新建的失败构建缓存，保留已存在的同名缓存和其他构建。回收最近一代时，只有存在根壳的构建参与可用历史选择；空或安装未完成的缓存不挤掉上一代，也不在另一 worker 安装期间被回收。字体、本机正文、附件和旧稿继续受既有保护。

正文使用 SQLite WAL、synchronous=FULL，快照加增量日志。每 32 次更新或日志达到正文限额两倍时压缩。保存确认仅代表当前服务器磁盘提交，不代表异机备份完成。

server:admin 支持 init、backup、restore、recover-attachments。初始化无公网入口；备份输出到全新目录，清单最后写入，包含数据库与全部索引附件的摘要。manifest v1 可选 recovery 条目包含保留原件的安全文件名、长度和摘要，旧备份没有此字段仍可恢复。恢复必须使用全新目录，完整性验证后轮换空间 epoch 和所有者恢复码，清除会话与邀请，暂停访问并停用非所有者。具体命令见 README，旧备份恢复后的资格复核见 PRD。

服务和离线附件恢复命令通过独立 SQLite 文件持有数据目录独占租约；服务进程退出或被强制终止后，操作系统释放锁。启动扫描发生在监听请求之前，逐个核验已索引文件的内容地址、长度及摘要。缺失文件仅从匹配原件修复，已存在却损坏、非法或无法修复的文件阻止启动；不覆盖现场。

崩溃遗留的内容地址文件及临时上传移入 attachment-recovery，先创建、同步并核验独立副本，再移除冗余上传路径，避免硬链接共享损坏。保留原件不自动新增在线索引或授权。停服后 recover-attachments 导出到全新目录，清单标注摘要、长度、内容地址是否确认和当前上传限额；临时文件可能只是部分上传。即使损坏索引阻止启动，仍可离线导出保留原件。人工核验后使用当前编辑身份和文档作用域重新上传，历史和原件不自动永久清理。

Service Worker 仅回收精确匹配本应用构建名的派生资源缓存。nonce 查询全部同源页面的构建版本，再复核仍存活的页面，保留当前构建、所有已回复的活跃构建及最近一代其他资源。未知、静默或新出现的页面使本次清理退出；清理不触及 IndexedDB、离线稿、附件、固定字体或其他应用缓存。根入口与原生文档深链在停服时使用本应用缓存壳，API 不缓存。

当前保护默认值：正文及单次更新 8 MiB、256 篇文档（含回收站）、50 MB 单附件、2 GiB 附件总配额、40 条连接、2 个并发上传、每连接每秒 60 条消息。身份尝试为每来源地址每分钟 20 次，不信任任意转发地址。正文、文档数、附件限额、连接数及 7 天邀请和 30 天会话可通过服务环境变量配置。这些是初始保护值，未完成目标环境测量。
