# CORE

## 身份与使命

pageTogether 是给自己和受邀朋友内部使用的共享文档与画板空间。产品以受邀成员共同记录、整理和创作为中心。

## 生命周期

生产保存与同步基础实现及验证中。已有独立生产工作区、邀请和空间权限、SQLite 保存、附件索引与备份恢复；具体证据和剩余验收见 CHANGELOG、ROADMAP。尚未实际部署，后续目标为用户指定的既有 ECS。

## 边界

编辑能力按 PRD 的完整原生能力要求实现；当前先验证公开发布版的完整接入路径。权限和离线重连边界见 PRD。企业组织、计费、公开注册和复杂资源权限体系不在当前范围。

## 绝不

不以昵称替代身份认证，不匿名开放共享内容，不导入雇主资产，不将浏览器缓存误称云端保存，不让离线稿绕过当前授权和文档生命周期，不公开私人数据或凭证。
