# ARCHITECTURE

## 目标组件与数据流

浏览器挂载 BlockSuite，Yjs 承载文档状态。Node.js 单进程提供静态资源、空间邀请和权限、WebSocket 同步与保存确认；SQLite 和独立附件目录负责持久化。当前只支持一个共享空间、一个服务实例。

## 当前实现

本地验证壳为 TypeScript、Lit 与 Vite 6.4.4；@blocksuite/affine 0.22.4、Yjs 13.6.33 通过完整 Store/View 扩展管理器挂载，保持正文与画板共用文档。具体能力与版本依据见 EDITOR_CAPABILITIES，取舍见 DECISIONS ADR-003。

src/editor 共享完整原生编辑器与宿主服务适配。src/app 使用自行实现的 ProductionWorkspace/ProductionDoc、独立 Y.Doc、IndexedDB 和带保存确认的 WebSocket 同步；目录来自服务端，标题从原生 page 块投影到 SQL。生产入口为 /，src/lab 的 test-only TestWorkspace 仅在 /lab.html 使用。

依据 ADR-029，ProductionDoc 挂载前核验并修复无 Yjs 历史的空目录记录。shared/native-document 仅依赖 Yjs，构造固定版本的原生四块、文本、子块数组和 surface 包装 Map；服务端初始化事务使用正常 push 保存。原生 New Doc 的本机同步创建仍保留，服务端拒绝双根合并，DocumentSync 在实际应用远端更新前保留冲突原稿并持久暂停。探测仅在本机根结构变化或初次待发同步时克隆，不在普通文字更新上反复复制全篇。

发布包导出 TypeScript 源码。Vite 使用上游同类 WASM 与 vanilla-extract 插件，保留原生 effects。宿主类型检查通过 scripts/check-types.mjs 映射到同版本随包发布的声明文件，避免把第三方源码内部诊断混入宿主检查；运行构建仍使用原始源码。useDefineForClassFields 与上游保持 false，库类型支持 ESNext。

开发预构建排除原生源码包，保留 .css.ts 插件处理；通过 TypeScript AST 收集其外部运行入口，转换 CommonJS 与深层依赖；显式编译装饰器。实际接入事件见 MEMORY。

依赖审计发现旧传递依赖 KaTeX 与 Vitest 问题。锁定覆盖为 KaTeX 0.18.2、Vitest 4.1.11；实际构建和公式渲染分别验证，不能以审计零报告替代行为验收。React 18.3.1 仅用于满足上游图标模块 peer，宿主使用 Lit。构建保留第三方许可原文。

## 保存与离线边界

依据 ADR-034，shared/content-references 直接遍历原生 Y.Text delta、嵌套 Map 和快照属性，统一盘点脚注中的文档与附件引用。脚注原件的缓存文件名和类型也从相同原生属性读取。ProductionDoc 的附件上传作用域和正文发送前检查、原生 ZIP 原件打包与导入前校验均使用该盘点。导入先将原件交给原生 AssetsManager 写入同一生产 BlobSource，再应用快照，防止脚注正文先取得保存确认。脚注视图通过公开 FootNoteNodeConfigExtension 接入直接徽标、键盘和弹层动作，复用当前文档导航和 BlobEngine；异步下载结束时复核当前编辑器作用域。

src/app/storage-usage 独立观察浏览器存储估算，合并并发查询、设置截止并在退出工作区时移除观察。无法读取时保留最后成功估算，提示来自上次测量，不改变正文、附件或同步队列。估算和实际保存失败分别处理，见 ADR-035、SPEC。

IndexedDB 原子保存合并快照与待发增量；不同标签页的确认只删除对应增量。附件按成员和空间代际缓存，已读附件也保存到本机。构建时生成 Service Worker 预缓存应用、字体和编辑器资源，API 始终直连服务端。实现依据见 [Yjs 离线支持](https://docs.yjs.dev/getting-started/allowing-offline-editing)。

重连数据流为本机草稿准备、当前身份和文档状态核验、获准的 Yjs 更新交换、服务端持久化及保存确认。文档增量同步依据公开 [Yjs 更新接口](https://docs.yjs.dev/api/document-updates)；正常合并与异常保留行为以 PRD 为准。

HTTP、WebSocket 与附件访问共用权威成员和权限状态，成员角色及文档生命周期由服务端控制。查看连接只接收获准内容，客户端提交的协同数据不能自行修改授权。删除、撤权与备份恢复需要阻断旧连接和旧离线稿自动写回。

正文和附件分别产生保存确认，未上传附件会阻止整体显示云端已保存。备份包含同一数据库快照中的目录、权限和附件索引，并复制其不可变文件；恢复到全新目录。同步事件不能解释为保存确认，具体恢复验收见 PRD。

## 已实现的生产基础方案

依据 DECISIONS ADR-009，服务端为 Node.js 22 单实例，SQLite WAL 与 synchronous=FULL，附件独立目录。SQLite 表管理成员、会话、邀请、文档生命周期、Yjs 快照与增量、附件索引及空间恢复代际。权限和文档目录不由客户端 Yjs 数据控制。

同步使用版本化 WebSocket 消息，先核验 Cookie、Origin、当前成员、空间代际及文档代际，再按状态向量返回增量。写入在同一同步事务内复核资格、校验更新、落盘并产生修订号，提交后广播和回复保存确认。重复更新安全重试，保存失败不污染权威内存状态。

删除及恢复均推进文档代际，恢复备份推进空间代际；旧客户端须保留离线稿并停止自动写回。每个消息及对外广播均复核授权，撤权主动终止现存连接。心跳和重连对账处理半开连接。

附件先写受限临时文件，校验内容地址并同步文件，原子发布后再提交索引。提交前再次核验权限，配额或 SQL 失败时清理本次新建的未索引文件，不删除已有附件。依据 ADR-030，server/blob-recovery 持有独立 SQLite 租约，启动前核验索引附件并保留崩溃孤儿和部分上传；恢复副本通过独立复制、核验及目录同步脱离硬链接。缺失索引文件仅用摘要匹配的原件修复，损坏索引文件阻止服务启动，离线导出仍可保全原件。备份包含保留原件，恢复到新目录后默认暂停访问、失效旧凭据和重审成员资格。关闭服务等待在途请求退出后释放数据库和租约。

浏览器持久层按成员、空间和文档代际隔离缓存；重连前保存完整离线稿，身份切换、降权或代际变化时停止自动上传。每次核验当前成员后，同步更新原生 Store 的只读状态和本机身份元数据，离线重开沿用最后核实的角色；缓存中不存认证凭据。已有缓存时先加载本机内容，无缓存时先等待首轮同步再挂载原生编辑器。删除或恢复时保留旧 Doc 的离线导出，并使用新代际打开恢复内容。

依据 ADR-011，成员资格历史由服务端权限版本表达；SQLite 采用增列迁移，不重建成员数据。IndexedDB 升级到版本 2，新增按文档作用域保存的授权版本与暂停原因。异常暂停不能靠刷新或恢复会话消除；无授权记录的旧待发队列保留并暂停。用户明确重新读取云端时，在同一本机事务中先保存完整旧稿，再隔离原队列和缓存，以新的 Y.Doc 读取云端；旧内存和草稿继续可导出。旧空间代际的正文及附件可一并导出。离线附件记录产生时的权限版本，身份失效后暂停或授权版本不匹配的附件保留供导出，不自动上传。

依据 ADR-014，本机持久层现为版本 3，仅增加 blobDrafts 存储，保留已有正文、附件和授权记录。src/app/blobs 实现原生 BlobSource 和状态流，文件按内容地址与空间代际缓存，保留文件名、类型、所属文档和产生时的权限版本。新附件离线时也先绑定文档作用域，随后核验当前身份再上传；上传期间新增的队列继续排空。服务端回执与本机队列 ID 匹配，回执落盘失败持续提示并等待明确重试。

宿主“添加附件”通过原生 BlobEngine 和 Store 创建附件块，原生文件入口仍保留；共享文件大小服务约束为 50 MB。正文同步在发送前检查引用的待发附件，附件保存成功后唤醒正文同步。下载先读取本机，缺失时通过鉴权接口读取并校验内容，缓存失败则保留内存原件。附件管理窗口汇集本成员各空间代际的缓存、原始副本与内存文件，明确重新提交先原子归档并重排附件，再核验保存并追加原生卡片，不应用旧正文更新。

缓存附件预览独立于正文写入，图片和媒体使用本机 Blob URL，HTML 等文档按 UTF-8 纯文本显示并限制前 128 KiB。关闭预览停止媒体并释放 URL。格式或编码不支持时保留下载入口。原生图片跨成员可能没有文件名和 MIME，缓存预览仅补充 PNG、JPEG、GIF、WebP 的文件头识别，不将未知文档作为可执行内容打开。

ADR-017 更新了 ADR-015 的 PDF 渲染方式：固定 pdfjs-dist 6.4.299，首次打开时加载同版本阅读器和 worker；CMaps、标准字体、WASM 解码器与 ICC 配置随构建保留并进入离线资源缓存。共享 PdfPreview 仅读取缓存 Blob 或同源 Blob URL，绘制当前页并提供分页及当前页文字，不运行 PDF 动作或嵌入附件中的页面。原生 AttachmentEmbedProvider 只替换 PDF render，保留原生转换、块模型、编辑与下载动作。画布像素与边长在分配前受限，加载和绘制设 30 秒截止，加密或损坏时保留原件下载；关闭或切换文档取消渲染并释放 worker。PDF.js 要求 Node.js 至少 22.13.0，未升级 BlockSuite 或 Yjs。

PDF 阅读器自身不可编辑，分页与文字展开控件局部位于原生 Note 遮罩之上，并停止相关鼠标事件向编辑器冒泡，使画板中的查看成员也能操作阅读器；其余 Note 区域继续使用原生选择行为。分页仅改变本地阅读状态，独立查看成员的正文、画板翻页及被拒绝的系统文件和富文本粘贴均未产生服务端文档修订。

依据 ADR-018，原生 HTML 文本匹配器仅补充行内纯空白节点折叠为一个空格，其余解析、格式和块快照沿用原生管线，代码及显式 trim 保持原处理。生产 NativeBlobEngine 将 RxJS 状态通知置于 Preact untracked 边界，避免 ResourceController 的同步订阅把消费者状态读取误记为外层 effect 依赖；数据缓存、状态流及鉴权保存规则不变。

BlockSuite 0.22.4 的原生 FileDropExtension 遇到第一个接受的处理器即停止，混合图片和其他文件会漏项。宿主在完整扩展之后覆盖两类原生 drop 配置，过滤各自文件组并让混合事件继续处理；实际块创建仍复用原生回调，查看 Store 拒绝处理。适配依赖该固定版本的私有 DI 标识，升级时须复核标识、注册顺序和正文/画板行为，不混装或修改上游包。

本机回归使用 fake-indexeddb 6.2.5 测试实际持久层代码，另由真实 HTTP 过期测试驱动 DocumentSync；该依赖仅用于开发测试。浏览器持久保存与恢复效果仍以独立浏览器操作和实际导出文件为证据。

本机写入或保存确认清理失败后，DocumentSync 持续标记存储失败并停止发送待发正文。后续编辑保留在内存，不能用同步、云端或异常暂停状态覆盖失败提示；退出和关闭页面提示保留未落盘内容。明确重试时先保存完整内存快照，再继续核验与同步；已经暂停的稿件继续受暂停保护。IndexedDB 事务完成 Promise 在创建时即观察失败，避免请求先拒绝时产生未处理的事务拒绝。

离线稿窗口汇集本成员的保留稿、设备缓存、旧代际及当前与隔离后的内存稿。每侧通过独立 SnapshotDoc、完整原生扩展和只读 Store 渲染正文或画板，预览没有网络同步和附件写入通路，附件只读本机已缓存副本。文字差异仅提取原生文本并比较行的出现次数，不改写完整 Yjs 快照。人工追加前核验当前会话、权限、代际、文档目录和保存状态，先保留当前完整稿，再通过原生 Store 添加用户确认的文字段落，原稿不变；图形和格式的语义合并不在此入口内，见 ADR-013。

## 原生引用、数据视图与内容迁移

原生数据表、表格和看板沿用完整 Store 扩展；宿主约束被视口裁切的原生菜单高度。文档导航共用同源 URL 解析，接受根路径的 doc 查询参数及原生 /workspace/main/:id，服务端为后一种路径返回应用壳，数据接口继续鉴权。目录成员或文档代际变化后重建原生视图上下文，清除上游引用视图缓存的已删除状态和旧 Store，保留同一份当前 Yjs 数据。

依据 ADR-021，生产 Store 统一启用原生数字格式并提供当前 WriterInfo，原生创建时间由块元数据计算。Vite 对固定 0.22.4 的数据视图源码入口作最小构建转换：嵌套筛选信号跟随当前父组，新增条件使用原生字段菜单；数字输入保留未变的原值、零值及明确百分比。链接单元格转发数据库行和坐标参数，表格及看板筛选读取全部属性，图片空值不生成图片元素，桌面看板补齐已有封面配置的渲染。保留原生模型、求值器和历史，不修改安装包，版本与片段不匹配即停止构建。

依据 ADR-023，通过公开 SlashMenuConfigExtension 补齐固定版本缺失的 Todo 注册，以 WorkspaceTodoSource 复用完整 DatabaseBlockDataSource、DataViewRootUILogic、属性和视图组件，适配独立 affine:data-view 的模型。QueryIndex 使用文档对象追踪来源订阅，冷载入即扫描，删除与新代际替换时解除旧订阅；行键包含文档和块标识。挂载期间按目录修订读取鉴权 HTTP 来源，避免汇总为每篇文档新增连接；来源写入继续走原保存与授权管线。该汇总当前只收集原生 todo。

依据 ADR-025，QueryTableView 和 QueryTableRow 扩展原生表格管理器与行移动，在视图数据中保存 manualRowOrder；原生筛选、排序和分组管线继续执行。组合行键经纯函数排列，保留缺失来源的位置并追加新来源，不改动来源正文。复制属性规范直接值和原生包装值，克隆富文本以保持副本独立；创建时间直接读取来源块元数据。内容迁移同时重映射手动顺序和原生分组顺序。

依据 ADR-026，独立汇总转换属性时取当前行与持久单元格行的并集，兼容直接值和包装值；复用公开 databasePropertyConverts、updateProperty 和 updateCells，在同一事务更新列及全部结果。转换仅修改当前汇总，固定列及只读保护在入口执行。上游文本转标签的两处字典通过固定版本构建转换改用无原型对象，原生十四条转换语义不变。

依据 ADR-027，原生图片单元格及桌面封面复用 DataViewImage，加载错误、同 URL 重试和资源变更只更新临时组件状态。直接 img 使用 no-referrer，保留无 CORS 图片的展示路径；空值不创建元素。不增加图片代理、资源抓取、上传或缓存服务，模型中保留原始字符串。

目录读取失败时，网络或服务异常仅回退到通过 LocalPersistence 授权记录检查的缓存，提示核验未完成；明确身份、权限或代际拒绝不走回退。此路径不创建连接或上传缓存，当前汇总的离线排序继续由原同步队列保存和核验。

依据 ADR-022，引用事件携带原生定位参数，URL 解析和生成保留同一组参数。主编辑器及其中嵌入视图可发起导航，其他编辑器的事件不串入；文档准备和视图渲染完成后使用原生 HighlightSelection 与滚动锚点，画板坐标使用原生 viewport。异步导航核对工作区、Doc 和视图代次，历史导航不重复追加历史项。

依据 ADR-020，原生同步创建文档接口仍立即返回 Doc；其初始化写入先等待 HTTP 创建成功和本机授权记录确认，再进入持久队列。目录广播由 CatalogRefresh 合并为串行读取，本地创建前后使旧读取失效，待创建文档不因旧目录缺项而被误退役。导入按篇创建与初始化，避免后续转换失败留下整批空壳；中途失败保留已有内容，空文档中断修复入口仍待补齐。

依据 ADR-019，src/app/transfer 复用公开 Transformer 和 Markdown、HTML、PlainText、NotionHtml 适配器。文本导出仅在临时快照中去除无值单元格、对齐静态表头并投影创建时间，不改变实时数据或原生快照。资源 ZIP 路径与原生图片适配器输出一致。Notion 的页面映射相对于每篇源文件计算，沿用原生 HTML 匹配规则。

原生 ZIP 包含快照、附件与版本清单。导入完整预检后分配新文档 ID，仅改写包内的原生文档引用，保留块、单元格、图形和画框标识；附件校验 SHA-256 后沿用原生 BlobEngine 与鉴权保存顺序。fflate 0.8.3 分块解压，按实际字节和文件数限制内存输入，具体边界见 SPEC。工作区级操作锁和结果状态跨目录刷新保留。PNG/PDF 复用原生 ExportManager，实际下载交付须按浏览器验收。

原生导入期间，仅该 ProductionDoc 的 WriterInfo 暂时返回空，阻止 BlockMetaService 把历史创建和修改元数据改成导入身份及时刻；完成或失败均恢复当前身份。其他文档和后续真实编辑继续使用原生元数据服务。

原生内容迁移不包含身份、权限或服务端历史，不能代替服务备份。空间导出会加载所含文档，仍受每文档连接和全局 40 条连接的限制；本轮只覆盖 25 篇原生往返，没有提高保护限额或宣称 100 篇并发导入容量。

## 在线成员与远端选择

依据 ADR-012，原生 Awareness 通过同一鉴权 WebSocket 的独立消息传输，保持 y-protocols 1.0.7 的二进制时钟和 selectionV2 结构。lib0 0.2.119 从同一安装图显式声明，用于验证和重编码；上游版本未升级。服务端 PresenceRooms 按空间代际、文档代际及文档 ID 管理临时房间，绑定连接所拥有的客户端 ID，并用已认证成员覆盖昵称、成员标识、角色和颜色。每次收发复核资格，断开、撤权或生命周期变化时移除远端状态；临时状态不进入 SQLite 或正文修订号。

客户端复用原生 AwarenessStore，远端正文光标、选择和画板指针由原生组件渲染。仅当前文档发布活跃状态，切换文档清空旧选择；成员列表按稳定成员 ID 去重，并提示同一成员的多个页面。断网时清除远端状态并显示在线状态不可用。实现依据见 [Yjs Awareness](https://docs.yjs.dev/api/about-awareness)。

独立浏览器的正文、基础画板图形、离线重连、权限、远端状态、本机配额故障、附件上传下载、异常重提及多类预览已有行为证据。正文系统输入、PDF、文档引用、数据表与主要迁移格式已补验，原生 25 篇文档与 6 个附件往返通过。嵌套筛选、数字格式、创建时间、正文和远端画框定位，以及复杂文档、独立汇总、字体和重启读回的各批独立范围见 EDITOR_CAPABILITIES。本轮复跑 10 人和 50 MB 固定服务容量方案，见 CAPACITY；画板系统拖入、其他原生能力与格式、长期压力与 ECS 仍待完成。

依据 ADR-031，构建指纹写入应用壳与 Worker，src/app/application-cache 回复带 nonce 的构建版本查询。Worker 复核全部存活同源页面，有未知页面则放弃清理，否则保留当前、全部活跃及最近一代派生资源。只删除本应用资源缓存，不操作正文、附件、离线稿和独立字体缓存；旧模块仅从获准保留的本应用缓存读取。真实双标签跨三代构建已验证，存储接近配额仍待测。

公开依据：[SQLite WAL](https://www.sqlite.org/wal.html)、[同步强度](https://www.sqlite.org/pragma.html#pragma_synchronous)、[better-sqlite3](https://github.com/WiseLibs/better-sqlite3/releases/tag/v13.0.3)、[ws 鉴权示例](https://github.com/websockets/ws#client-authentication)、[Yjs 更新接口](https://docs.yjs.dev/api/document-updates)。具体已实现接口和验证结果随代码同步 SPEC、CHANGELOG。

## 原生画板字体

依据 ADR-024，沿用固定 CommunityCanvasTextFonts 的七种字体和 29 个公开资源。Service Worker 只缓存精确列出的上游字体 URL，成功且可跨源读取的响应才进入独立字体缓存；激活时预热，运行时缓存优先，失败仍由原生加载器处理，API 不缓存。

ADR-032 补充同源 pageTogether Han Supplement，固定 BabelStone Han 16.0.3 的 32,993 个补充平面汉字映射，修改名、原始许可和覆盖摘要随应用保留。公开 FontConfigExtension 注册该字体；固定版本构建转换仅为原生 wrapFontFamily 增加字形回退，使测量、编辑和画板绘制一致。正文 CSS 共享该回退，不改模型中的七种字体标识。视觉导出同时等待该补充 FontFace，加载失败时停止，避免字体集合 ready 完成后仍导出缺字。约 4.83 MB 字体进入应用资源预缓存，没有新增外部字体服务或 npm 版本升级。

FontStatusExtension 观察原生 FontLoaderService 的实际 FontFace 完成状态。宿主仅更新字体状态元素，不重新挂载编辑器，以免字体完成事件再次创建加载器。未完整加载时明确提示备用字体可能出现，已成功缓存的资源可离线读取；首次使用与清除缓存后仍依赖字体源可达。

## 原生视觉导出适配

依据 ADR-028，VisualExportManager 继承固定版本 ExportManager，通过规范的类标识覆盖 DI，保留原生正文及画板栅格器、PDF 打包和模型。构建转换关闭默认上游公共图片代理、缩短原生就绪等待并检查其失败结果，通过可取消文件事件交付原生生成的文件；版本或目标源码片段变化直接拒绝构建。上层仅在取得格式和文件头匹配的文件后提供 Blob 下载入口，异步各阶段核对当前编辑器作用域，监听在 finally 释放。

预读等待字体、检查可见错误并缓存直接读取和实际解码的图片。html2canvas 的惰性副本中才内嵌这些字节，延续原生 SVG viewBox 尺寸规范；数据视图缩略图及封面预绘到克隆显示框，补齐 html2canvas 1.4.1 不支持 object-fit 的比例问题。最终替换到副本中的图片完成 decode 后才交给同步读取内在尺寸的原生解析器，避免 Safari 以零尺寸省略图片。Safari 返回的 oklab 等颜色由浏览器画布转换为 RGB，再写入克隆样式。上述操作不修改 live DOM 样式、源 URL、Yjs 内容或修订号。

实际样式扩展环境出现导出阻塞，临时样式隔离对照进一步复现了现代颜色解析失败。入口对已知 Dark Reader 标记明确提示换窗口，不修改浏览器设置；不能据此保证其他扩展兼容。资源及图片画布限额见 SPEC，字体覆盖与桌面浏览器实际证据见 EDITOR_CAPABILITIES。

ADR-033 补齐画板视口裁剪兼容：src/editor/visual-blocks 通过原生 GfxViewportElement 临时激活被裁剪的区块，等待显示完成后才进行资源预读和原生栅格化。finally 按当前视口与选择恢复状态，不改模型；固定构建转换同时拒绝零尺寸区块画布。思维导图正文引用的原生占位提示修正查看方向，实际图形与编辑仍在画板，不伪造正文预览。
