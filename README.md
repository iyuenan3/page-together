# pageTogether

A shared document and whiteboard space for friends, built with BlockSuite and Yjs.

## 状态

2026-10-09 立项，当前仅包含产品约定与项目骨架。应用尚未实现、部署或开放试用。

## 产品方向

- 邀请进入，填写昵称，无需邮箱注册。
- 空间内共享文档，提供正文、画板与实时协同。
- 保留选定 BlockSuite 版本的完整原生编辑能力，按能力清单逐项验收。
- 服务端管理访问资格、持久化、附件与资源限制。
